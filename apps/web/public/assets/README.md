# Logo oficial

Coloque aqui o arquivo **oficial** da logo da Gestão Contadores com o nome exato:

```
logo-gestao-contadores.png
```

- Não crie, desenhe ou redesenhe a logo: use somente o arquivo fornecido pela empresa.
- Enquanto o arquivo não existir, o sistema exibe apenas o texto "Gestão Contadores".
- A API usa o mesmo arquivo nos PDFs (variável `LOGO_PATH` no `.env`).
- Recomendado: PNG com fundo transparente, altura mínima de 120 px.
